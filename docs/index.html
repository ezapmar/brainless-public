A second brain, woven from your own notes.

Notes arrive from everywhere, collect in one folder, link themselves to each other and come back to you when they are relevant. Then they argue with you, through one chat on your phone.

The loop

Four knots. Each one holds because of the one before it.

Collect everything without judging it. Let the machine read it and make the connections. Argue with what you are about to decide. Write the decision down as a bet, and settle it later.

göz · the eye

Collect

Everything comes in through one door. A voice note, a photo of a handwritten page, a link, a PDF, a meeting transcript, a line typed on the phone. Nothing is tagged, filed or judged on the way in.

hayat ağacı · the tree of life

Link

The machine reads it so you do not have to. Every note is summarised and tied to the people, companies and ideas it names. An idea that keeps coming back gets a page of its own, and every new source improves that page.

koçboynuzu · the ram's horn

Argue

Before a real decision, /decide quotes what you believe and what you decided before, and asks first what undoing it would cost. Every night each new source is read against the pages nearest to it, and a contradiction reaches you in the morning.

yıldız · the star

Decide

A decision is written as a bet, with a prediction and a review date. When the date passes you grade it in one line, so you stop being wrong the same way twice.

How it runs

One Mac, four jobs, one chat.

No second machine, no relay, no VPN. The phone talks to a Telegram bot and opens the vault from iCloud Drive. Everything else happens on the Mac, in four launchd jobs, and only one of them ever writes to git.

capture

every two minutes

Reads the bot. A plain message becomes a note, a reply to the bot approves or defers, a message starting with ? gets an answer cited from your own pages.

hourly

every hour

Cheap work that should not wait for the night: tasks, mail, a brief before the next meeting, and the morning set once a day after seven.

night

23:00, or on wake if the lid was shut

One ordered chain: ingest, digest, compile, index, links, lint, the Sunday weeklies, the health check, then the day's single commit and push.

llm

always on, 127.0.0.1:8080

Gemma 4 12B on llama-server. The short, private jobs run here and never fall back to the cloud. If it is down, the job waits; the text stays home.

Everything the system says to you goes through one durable outbox: queued before it is sent, retried, sent at most once.

Yours

On your disk, in plain text, with the private parts on your own model.

A folder of Markdown

No server, no account, nothing to sign up for. Your notes stay in your folder, in a format you could still open in twenty years. Obsidian if you like it, any editor if you do not.

Two models, by job

Short private jobs (classifying a note, reading a photo, answering a question) run on the model on your Mac. The pages everything else reads are written by Claude on a subscription. Each job is a named lane you can move.

Secrets outside the folder

The bot token and the chat id live in ~/.config/brainless, never in the vault, because the vault is a git repository, and a git repository is where keys go to leak. The nightly push refuses a remote that is public.

A compiled layer you can regenerate

You own the source notes. The machine owns a wiki of summaries, concept pages and digests on top, and it can rebuild that layer from scratch at any time.

Set it up

An afternoon on a Mac. Two minutes to the first note.

You need git, Homebrew, Python 3.13, a Telegram bot and the Claude CLI. Fill in the profile, put the bot token in ~/.config/brainless, add a Gemma 4 12B model file for the local lanes, then install the four jobs. The README has every step.

Get the engine
git clone https://github.com/ezapmar/brainless-public.git ~/projects/brainless
Install the jobs
bash .agents/launchd/install.sh

Run it again after changing a path; --uninstall removes the jobs.

The name is a joke that stuck.

In the office I kept saying "let us use our own brain first, then we can talk about a second brain", so when the folder needed a name I typed brainless. Not a second brain, zero brain. The joke carries the design rule anyway. The system keeps the memory and the connections; the thinking stays yours.

The mark is a brain drawn as a kilim. The motifs are the weaver's own, from the looms of Anatolia and the steppe: the eye, the tree of life, the ram's horn, the star, the figure with hands on hips. Notes are the motifs. Links are the threads. The mind holds because each knot is tied to the others.
