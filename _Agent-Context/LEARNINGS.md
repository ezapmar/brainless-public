# Learnings

Your standing preferences and the lessons from correcting an agent, for every agent that works in this vault: Claude sessions (the SessionStart hook loads this file), the Buzz agents and the reply worker. AGENT-RULES.md sets the rules; this file says how to apply them well, and the rules win on a conflict. Add an entry each time you correct an agent, in the same shape.

## Language and style

**1. Example: no em or en dashes anywhere, file names included.** Use a comma, colon or full stop instead.
Why: a strong preference; it kept coming back.
How: scan before delivering.
